My Projects

A selection of projects that demonstrate my skills in web development, UI/UX design, and digital branding.

MediWings Website

A responsive healthcare drone service website developed in my first year as a web developer.


This was my first complete website project, where I learned to build responsive navigation for mobile devices. I used CSS media queries and JavaScript to create a hamburger menu and improve usability. If I rebuilt it today, I would use a mobile-first approach with Figma.


This project connects with the MediWings Mobile App, showing how the same healthcare solution can function across both web and mobile platforms.

Mabunda Matimu Studio

A professional brand guideline developed to ensure visual consistency across digital and print materials.


This project taught me the importance of consistency in branding and design. I initially chose colours based on appearance, but later learned some combinations failed accessibility contrast standards. After researching, I improved the colour palette to ensure better readability and usability across different platforms.


The design system principles from this project influenced the visual structure of my portfolio, including colour hierarchy and typography.

View Project

UniEats Website

An e-commerce platform that sells and delivers food to students around universities in Cape Town, operating 24/7.


This was my first e-commerce project, where I learned how to structure product listings and design a user-friendly checkout flow. A key challenge was designing for students with limited mobile data, so I optimised images and simplified the interface. If I rebuilt it, I would add dark mode and further improve the mobile checkout experience.


The E-commerce like McDonald's helped me to influenced the visual consistency and design structure of UniEats.

View Project

Massive Dynamics Branding

A branding design project created for Massive Dynamic as part of my second-year university assignment.


This project taught me how to present a complete branding system to a client using clear rules like colour codes, typography, and logo spacing. The biggest challenge was creating a scalable design that worked across different formats, from business cards to large displays. If I improved it, I would include more realistic mockups to show how the brand works in real-world applications.


The structured branding approach used here influenced the visual identity and design decisions applied in the Mabunda Matimu Studio

MediWings Mobile App

A MediWings mobile application designed in Figma that enables drone delivery of medicine to remote areas.


This project introduced me to mobile UI/UX design and the importance of larger touch targets and thumb-friendly navigation. The biggest challenge was prototyping the drone tracking feature, which I solved by studying existing delivery tracking interfaces. If I improved the design, I would conduct user testing to better validate navigation and user interactions.


This mobile application complements the MediWings Website, demonstrating how a single service can operate across multiple digital platforms.

View Project

Lamine-Yamal Portfolio

A personal project developed during university recess to showcase the journey of football player Lamine Yamal.


This project allowed me to practise my frontend development skills outside of academic work. I learned how to design a visual timeline and present athlete content in an engaging way. The main challenge was balancing a dynamic sports theme with a clean and professional layout. Looking back, I would include video highlights to create a more immersive storytelling experience.


This mobile application complements the MediWings Website, demonstrating how a single service can operate across multiple digital platforms.
